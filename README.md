# German Vocab

A vocabulary learning app for German A1–B2 learners.

**Live:** https://sinanbaymammadli.github.io/german-vocab/

## Features

- **New** — quiz yourself on unlearned words with 4-choice questions. Reveal the answer if you're stuck.
- **All** — searchable list of all words with status filter (All / New / Seen / Learned).
- **Word states** — every word moves through three states: _new_ → _seen_ (revealed or answered wrong) → _learned_ (answered correctly).
- **Progress bar** — shows learned and seen segments so you can track how far through the deck you are.
- **Level picker** — toggle A1, A2, B1, B2 directly in the header. Select multiple levels at once.
- **🔊 Audio** — tap any word to hear it pronounced in German.
- **Cross-device sync** — sign in with Google to sync progress and settings across devices.

## Stack

- React + Vite
- React Router
- Firebase Auth + Firestore
- GitHub Actions → GitHub Pages
