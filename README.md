# German Vocab

A vocabulary learning app for German B1 and B2 learners.

**Live:** https://sinanbaymammadli.github.io/german-vocab/

## Features

- **Learn** — quiz yourself on new words with 4-choice questions. Reveal the answer if you're stuck.
- **Learned** — browse all words you've marked as learned, sorted by most recently learned.
- **All** — searchable list of all 1,703 words (992 B1 + 711 B2) with status indicators.
- **🔊 Audio** — tap any word to hear it pronounced in German.
- **Cross-device sync** — sign in with Google to sync progress and settings across devices.

## Word levels

Switch between B1, B2, or both in **Settings**. Your choice syncs to the cloud.

## Stack

- React + Vite
- React Router (hash-based)
- Firebase Auth + Firestore
- GitHub Actions → GitHub Pages
